# Aria landing

Marketing page for Aria, the AI employee that lives in Slack. Built with Astro 7, React islands, Tailwind 4, GSAP and Lenis.

```bash
pnpm install
pnpm dev       # http://localhost:4321
pnpm build     # static output in dist/
pnpm preview
pnpm check     # astro check (TypeScript 6.x)
```

See `AGENTS.md` for the code layout, `DESIGN.md` for the visual system, and `MOTION.md` for the motion spec.
