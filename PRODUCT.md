# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro 7 + React islands + TypeScript + Tailwind CSS v4 + GSAP + Lenis (Framer Motion inside islands only)

## Users

Small-to-medium business owners and knowledge workers who need an AI employee in their Slack workspace. Primary persona: a founder or team lead who wants someone to read channels, research, and produce artifacts (summaries, PDFs, schedules) without managing another tool.

## Product Purpose

Aria is a generalist AI agent that joins your Slack workspace as a named team member. She reads your channels, understands your business, browses the web, writes code, generates files, and produces deliverables. She is not a chatbot — she is a hire with the full capability of an OpenClaw agent.

## Positioning

The only AI agent that lives natively in Slack with full OpenClaw capabilities — web search, browser automation, code execution, canvas, file operations, cron scheduling, and multi-channel awareness. Other Slack bots are narrow integrations. Aria is a complete employee.

## Operating Context

- Lives in Slack threads and DMs
- Reads channel history with permission
- Produces artifacts: PDFs, summaries, schedules, research docs
- Requires approval for sensitive actions
- Transparent cost per run shown in thread
- Memory is readable and exportable

## Capabilities and Constraints

- Full OpenClaw tool suite: web search, browser, canvas, code exec, file ops, cron
- Slack-native only (no web chat widget)
- Requires workspace admin to invite
- Approval workflow for spending-sensitive actions
- 14-day free trial, no card required

## Brand Commitments

- Name: Aria
- No avatar (minimalist, text-forward identity)
- Voice: Direct, capable, warm — never generic AI-speak
- "Hire" metaphor over "subscribe" or "buy"
- HyperCLI brand: primary `#4f7cff`, teal `#6ce8c4`, dark `#10151f`
- Font: Figtree (Google Fonts)

## Evidence on Hand

- HyperCLI platform: agent.hypercli.com
- Pricing: Pro $149/mo, 3 large agents, 100M tokens/day
- Competitor reference: viktor.com ("Not a tool. A hire.")
- No testimonials yet — do not fabricate

## Product Principles

1. Slack-native, not bolted-on
2. Transparent by design — costs, memory, approvals visible
3. Generalist over specialist — one agent, many jobs
4. "Hire" language over SaaS jargon
5. Show, don't tell — live demo over feature grid
